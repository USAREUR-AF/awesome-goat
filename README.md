# Awesome goat [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Work that other people and organizations have built on [goat](https://github.com/USAREUR-AF/goatcore), the open-source data fabric: a WireGuard mesh, identity for people, machines and workloads, and publish/subscribe, run as one system across sites that lose their links.

This list is where the goat project highlights what others build on it. It is an open invitation to everyone who does: open-source projects, research groups, public bodies, and companies whose commercial or proprietary products work with goat.

## What belongs here

An entry is work that uses goat as its substrate: it depends on goat's mesh, identity and data fabric together, and would not work on one of goat's components alone. Work that uses only one component belongs on that project's list, for example [awesome-zenoh](https://github.com/kydos/awesome-zenoh) or [awesome-wireguard](https://github.com/cedrickchee/awesome-wireguard).

Entries come from the people who built the work. goat's own repositories are not listed here; they are indexed in the [goat documentation](https://usareur-af.github.io/goatdocs/).

A listing describes the work in its author's words. The maintainers check that the link works and that the entry says how the work uses goat. A listing is not an endorsement of any product, service or organization by the U.S. Army or the U.S. Government.

## Add your work

Open a pull request that adds one line to the section that fits, or open an [issue with the entry form](https://github.com/USAREUR-AF/awesome-goat/issues/new?template=add-entry.yml) and a maintainer will add it for you. The steps and the entry format are in [CONTRIBUTING.md](CONTRIBUTING.md).

An entry has this form:

```markdown
- [Name](https://example.org/product) - One sentence on what it does. Uses goat for: mesh, identity, fabric. By: Organization.
```

New to goat? Start with the [goatcore README](https://github.com/USAREUR-AF/goatcore#readme) and [your first goatnet](https://github.com/USAREUR-AF/goatcore/blob/main/docs/tutorials/00-goatlite.md).
